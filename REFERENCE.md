# Reference sources

## Purpose and scope

**Access date: 2026-10-18.** An authority-first reference register for a private collector's zh-Hant-first knowledge database of Chinese **ceramics, bronzes, jades and furniture**. It implements decision K1: begin with authoritative websites, then books by recognised authorities. It builds on KDB01, §3, without repeating its licence assessment. The owner's later permissions review does **not** affect inclusion or scholarly priority here.

This is a research bibliography, not an approved ingestion manifest. Museum attributions, archaeological dates and published authentication opinions remain attributed claims. Older catalogues can be important evidence of collecting history while being superseded on chronology. Auction material is explicitly a **market source**. Website rows count distinct research resources, not necessarily independent institutions; cross-category sources are listed once.

**Verification:** `V` = substantive page or documentation read successfully; `B` = read successfully in the collaborative browser after a command-line access failure; `U` = **unverified** (failure, access challenge, or content not inspected). An HTTP 200 access challenge is U. A reachable catalogue search shell verifies the route, not holdings or the book's bibliographic details. Public API documentation is not an importer acceptance test. Capabilities labelled “not established” are unknown, rather than absent. Unverified secondary links are labelled individually. Book metadata checked through institutional publication pages where possible, supplemented by edition-level Open Library catalogue records; those records aggregate library MARC and sometimes commercial metadata, so noted conflicts require the title page.

Chinese personal names and titles are displayed in **traditional characters**; mainland books may themselves be printed in simplified characters. English renderings following Chinese titles are descriptive translations unless an English edition is separately identified. Western authors retain their original names; established Chinese names are added where reasonably secure, without inventing transliterations.

## How to use (seed versus importer versus book ingestion)

| Use | Selection and handling |
|---|---|
| Curated seed | Start with P1 museum/research claims. Capture the exact object number or article, original language, date, page/section, attribution and uncertainty. Write reviewed zh-Hant explanations supported by those locators. Use excavation reports for production contexts; an accession label alone does not establish an authentication rule. |
| Website importers | First investigate NPM, Cleveland and Met, then Smithsonian, V&A, AIC and Harvard. Preserve provider IDs, exact field locators, retrieval dates and upstream attribution changes. Retain image **URLs only** and load remotely; do not copy images. URL exposure does not establish permission to hotlink or a stability guarantee. Record per-image rights separately from metadata rights. The owner decides permissions later. |
| Vocabulary alignment | Getty AAT and AAT-Taiwan supply concepts and zh-Hant terminology; Wikidata supplies multilingual IDs and discovery leads. Neither substitutes for the cited authority behind a historical or authentication claim. Keep inscriptions and marks literal, including variants. |
| LIV01 book ingestion | Prefer the four confirmed free PDF titles in the shortlist below. Select one or two short/structured candidates before a large exhibition catalogue. Pin edition, printed pagination and figure numbers. This task did not download a whole book. Free reading, a library loan and a freely downloadable PDF are different access states. |
| Library/purchase books | “Print/library only” means no lawful downloadable PDF was established here; it does not mean none exists. Use the linked WorldCat holdings search, request a library copy, or buy an authorised publisher edition. A loan does not itself authorise automated extraction. No shadow-library routes are included or permitted. |
| Priorities | **P1:** core seed/authority or unusually strong specialist evidence. **P2:** expansion, corroboration or scoped specialist coverage. **P3:** historical, discovery or market-context supplement. Priority measures research value, not permission status. |

**Facet key:** `M` material/category; `D` dynasty/period/reign; `K` kiln/workshop/maker; `T` technique/decoration; `I` marks/inscriptions; `C` condition/restoration; `A` authentication methods, attribution limits/red flags; `P` provenance/market history. Facets denote likely useful coverage, not a promise that every record contains them. `zh-Hant`, `zh-Hans`, `en`, `fr`, `ja`, `de` denote content languages; an English navigation shell does not imply translated object entries.

**Image/access key:** `API image` means documentation exposes an asset field or IIIF route; `page image` means images are delivered on pages, but a stable per-object URL was not established unless stated. `not checked` is explicit uncertainty. “Pages” means the public route observed; no API/bulk contract was established.

Chinese-language NPM publications are valuable but current NPM requests were blocked; no specific NPM book PDF is claimed verified.
3. **Edition uncertainties are localised, not silently resolved.** Geng C01 originating imprint; Krahl C08 exact boxed-volume coverage; Valenstein C13 1988/1989 issue and current page's 1975 hero field; Gettens B07 1967/1969 digital-series versus volume date; d'Argencé J07 museum issue; NPM J10 personal authorship; Wu J11 editorial role; several early books' ISBNs. 4. **Scientific authentication requires more recent specialist literature.** These sources support material observation, comparison and named authors' methods, not a general authenticity verdict. Add recent archaeometric studies, treatment histories and sampling/method limits before authoring claims about corrosion, thermoluminescence, spectroscopy, artificial ageing or modern repairs. Older typologies must remain dated evidence.
5. **Image exposure is unevenly verified.** API documents establish asset routes for the leading importer candidates; most page-only sources were not sampled to an individual stable asset. No image was copied. Delivery via HTML, IIIF or a PDF does not establish a durable hotlink or a per-object image licence. 6. **Rights are recorded, not adjudicated.** No source was excluded for NC/ND/reserved/unknown terms. The owner handles permission questions later.
