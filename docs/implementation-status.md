# Implementation status

This source-backed matrix tracks [Requirements](https://app.notion.com/p/3f7b2572f788812db92ae890b424de5a) against the first working draft. The [Reference](https://app.notion.com/p/3f7b2572f788812caf6eeb3886e03401) defines behavior. Focused tests and fresh-process HTTP checks cover bounded persistent paths. Historical v3 gates and later source-bound repair checks are recorded below. Strict coverage and complete native/provider acceptance remain incomplete.

**Implemented and Verified** requires the full named acceptance check on a stabilized source revision. **Implemented but Unverified** means the scenario's source is present without that complete check. **Partial** means source or executed evidence covers only a subset. **Blocked** names a concrete prerequisite that prevents required execution. **Not Started** means no demonstrated implementation beyond contracts/schema. No FR or PT is yet marked Implemented and Verified: focused server and component evidence does not establish complete native and provider acceptance.
